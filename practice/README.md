# Practice exercises

Every exercise has its own folder with a `README.md` (the same instructions you see in the
course website) and starter code. Everything runs with plain **Python 3.10+** and the standard
library — no installs needed (SQLite comes with Python).

Run an exercise from inside the `ddia-course` folder, e.g.:

    python practice/01-fault-injection/bank.py

Reference solutions are in `practice/_solutions/`. Try the exercise first: the struggle is
where the learning happens. Peek only after you have a working attempt or have been stuck
for 20+ minutes.

Check that every reference solution still passes:

    python tools/check_solutions.py
